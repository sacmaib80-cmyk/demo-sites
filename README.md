# demo-sites

งานตัวอย่างเว็บไซต์ 2 ชิ้น ร้าน โครงการ ราคา และบริษัทในเว็บเป็นของสมมติ ไม่มีการขายจริง และไม่มีข้อมูลที่กรอกถูกส่งออก

**เปิดดู:** https://sacmaib80-cmyk.github.io/demo-sites/

## ROMNGAO เว็บโครงการบ้าน

https://sacmaib80-cmyk.github.io/demo-sites/estate/

- เดินชมในบ้าน 3D ได้ทุกห้อง ขึ้นบันไดได้ ชนผนังจริง ใช้เมาส์ นิ้ว หรือ W A S D
- ลากเวลาดูแสงแดด ทั้งบนหน้าแรกและระหว่างอยู่ในบ้าน
- ภาพตัดบ้านคำนวณเส้นแดดจากขนาดจริงของโมเดล ส่วนทางเดินแดดเป็นแบบจำลอง
- แปลน โมเดล 3D และการชนผนังอ่านจากข้อมูลบ้านชุดเดียว (`estate/house-data.js`)
- หน้าแรกเป็นภาพนิ่งที่เรนเดอร์จากโมเดลเดียวกัน 3D โหลดเมื่อกดเดินเข้าบ้าน

ทำด้วย Three.js ไม่มีขั้นตอน build ภาพเรนเดอร์จากโมเดลในเว็บนี้ ไม่ใช่ภาพถ่าย

ทดสอบบน Chrome กับการ์ดจอ GeForce GT 710 ยังไม่ได้ลองบนมือถือจริง iPhone หรือ Firefox

## ตั้งใจดี ระบบรับออเดอร์ร้านเล็ก

https://sacmaib80-cmyk.github.io/demo-sites/order-bill/

- ลูกค้าเลือกของ ได้บิล ได้คิวอาร์พร้อมเพย์ แนบสลิป
- เจ้าของร้านเห็นออเดอร์ เปลี่ยนสถานะ แก้ราคา เพิ่มสินค้า ([หน้าหลังร้าน](https://sacmaib80-cmyk.github.io/demo-sites/order-bill/owner.html))
- ออกแบบให้ใช้กับ Google Sheet และ Apps Script ไม่มีค่าใช้จ่ายรายเดือน

เว็บนี้เปิดเป็นโหมดตัวอย่าง รันโค้ดหลังบ้าน `order-bill/backend/Code.gs` ในเบราว์เซอร์ด้วยตัวจำลอง Google ข้อมูลอยู่ในเครื่องคนเปิดเท่านั้น คิวอาร์เป็นเลขตัวอย่าง ห้ามโอนเงินจริง

ทดสอบบนตัวจำลองเท่านั้น ยังไม่เคยรันบน Google จริง
